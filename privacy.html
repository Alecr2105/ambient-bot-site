Ambient Bot ("the tool") is an internal publishing tool operated by a single channel owner. It is not a public service and has no users other than the owner. This policy explains what data the tool handles.

YouTube API Services

The tool uses YouTube API Services. By using it, you are agreeing to be bound by the YouTube Terms of Service. Data accessed through YouTube API Services is also subject to the Google Privacy Policy.

What data the tool accesses

  • Google account authorization. When the owner signs in with Google, the tool receives OAuth access and refresh tokens that allow it to upload and manage videos on the owner's own YouTube channel (scopes: youtube.upload and youtube).
  • The owner's own channel content. Video files, titles, descriptions, tags, thumbnails, playlist membership, publication schedule, video IDs and basic public statistics (such as view counts) of videos the tool published.
  • API quota usage for the tool's own Google Cloud project.

The tool does not access, collect or store personal data of any other YouTube user, viewer or commenter. It does not use cookies, analytics or advertising trackers.

How the data is used

Solely to publish and schedule the owner's videos, record the result of each upload, and avoid exceeding API quota. Data is never sold, shared with third parties, or used for advertising.

Where the data is stored

Everything is stored locally on the owner's own computer: OAuth tokens in a private file outside the application's code, and upload records in a local database. No data is sent to any server other than Google's.

Retention and deletion

Upload records are kept while the channel is active so the tool can avoid duplicate uploads. The owner can delete the local token file and database at any time. Stored YouTube API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the tool can no longer access the channel, and its stored tokens stop working.

Changes

If this policy changes, the updated version will be published on this page with a new date.
